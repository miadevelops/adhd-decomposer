# Tiny Steps 👣

An ADHD-friendly task decomposition app that breaks overwhelming tasks into tiny, doable steps.

**"Finally. A to-do list that gets ADHD."**

🌐 [Website](https://tinysteps-6hy.pages.dev) • 📱 [App Store](https://apps.apple.com/us/app/tiny-steps-adhd-task-helper/id6758985538) • 🤖 Play Store (coming soon)

## Why Tiny Steps?

For people with ADHD, starting tasks can feel impossible. "Clean the house" might as well be "climb Mount Everest." 

Tiny Steps uses AI to break down any task into small, concrete actions that feel achievable:

**Before:** "Clean the kitchen" 😰

**After:**
1. Walk to the kitchen (1 min)
2. Put away dishes on the counter (3 min)
3. Wipe down the stove (2 min)
4. Take out the trash (2 min)
...

Each step shown one at a time. Confetti when you complete one. No guilt if you skip.

## Features

### Core
- 🎯 **AI-Powered Decomposition** - Enter any task, get tiny steps instantly

- 🔗 **Deep Links** - Jump directly from notifications
- ♿ **Accessible** - Screen reader support, large touch targets, respects system settings

## Getting Started

### Prerequisites

- Flutter 3.24+ (tested with 3.47)
- Dart 3.5+
- Android SDK 36+
- JDK 17+ for Android builds

Android builds use the checked-in Gradle 8.14.3 wrapper, Android Gradle Plugin 8.11.1, and Kotlin 2.2.20; no separate Gradle installation is needed.

### Installation

```bash
git clone https://github.com/miadevelops/adhd-decomposer.git
cd adhd-decomposer
flutter pub get
flutter run
```

### Build configuration

Defaults point at the production API and RevenueCat project. Override them per build with `--dart-define`:

| Define | Purpose |
|---|---|
| `TINYSTEPS_API_URL` | Backend base URL (e.g. `http://10.0.2.2:8787` for `wrangler dev` from the Android emulator) |
| `REVENUECAT_ANDROID_KEY` | RevenueCat public SDK key for Android |
| `REVENUECAT_IOS_KEY` | RevenueCat public SDK key for iOS |

The Nunito and Inter fonts are bundled in `assets/google_fonts/` (with their OFL licenses), so the app never downloads fonts at runtime.

### Tests

```bash
flutter analyze
flutter test
```

### Build APK

```bash
flutter build apk --debug
# Debug APK at: build/app/outputs/flutter-apk/app-debug.apk
```

## Design Principles

1. **One thing at a time** - Never overwhelm
2. **Celebrate everything** - Dopamine is the feature
3. **No guilt** - Skip button always available
4. **Calm UI** - Soft colors, rounded corners, breathing room
5. **Fast to value** - Task → steps in <3 seconds
